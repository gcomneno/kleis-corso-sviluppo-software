# Kleis Software Lab — Percorso di apprendimento

Repository di esercitazioni sviluppate durante il corso di Sviluppatore Software.

Il repository raccoglie esercizi, appunti, correzioni, pre-test e Lesson Learned su:

- C#
- HTML
- CSS
- Responsive Design
- Bootstrap
- teoria e metodo di lavoro
- logica e problem solving

L'obiettivo NON è solo far funzionare il codice, ma:

- capire cosa si sta facendo
- organizzare il lavoro
- scrivere codice leggibile
- documentare ciò che si impara
- trasformare ogni esercizio in materiale riutilizzabile

## Struttura

Il repository è organizzato in quattro macro-aree:

- `csharp/` → esercitazioni e ripassi C#
- `web/` → esercitazioni HTML/CSS, responsive design e Bootstrap
- `test-prep/` → pre-test e materiali di ripasso
- `theory/` → appunti teorici, metodo, analisi e progettazione

Ogni esercitazione resta organizzata in modo indipendente:

- codice sorgente
- eventuali progetti `.csproj`
- file HTML/CSS
- immagini o tracce
- note didattiche
- Lesson Learned

## Approccio

Ogni esercizio segue alcune regole:

- codice semplice prima di codice furbo
- progressione graduale della complessità
- validazione dell'input
- naming leggibile e intenzionale
- metodi piccoli e responsabilità chiare
- separazione tra struttura, stile e logica
- Lesson Learned quando un argomento introduce concetti importanti
- commit Git piccoli e descrittivi

---

## Perché questo repository è utile

Questo repository è un diario tecnico del percorso.

Serve per:

- ripassare velocemente
- recuperare lezioni perse
- confrontare soluzioni diverse
- prepararsi ai test
- documentare la crescita tecnica
- mostrare un metodo di lavoro ordinato
