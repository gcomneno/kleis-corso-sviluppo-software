# Soluzioni commentate — Pre-test HTML/CSS

## 1. Risposta corretta: B

HTML serve a descrivere struttura e contenuto della pagina.

## 2. Risposta corretta: B

CSS serve a definire aspetto, stile e disposizione degli elementi.

## 3. Risposta corretta: C

Il contenuto visibile sta normalmente dentro `<body>`.

## 4. Risposta corretta: B

I link si creano con il tag `<a>`.

## 5. Risposta corretta: A

`target="_blank"` apre il link in una nuova scheda o finestra.

## 6. Risposta corretta: B

`<ul>` crea una lista non ordinata.

## 7. Risposta corretta: C

`<li>` rappresenta un elemento di lista.

## 8. Risposta corretta: A

Una tabella HTML si crea con `<table>`.

## 9. Risposta corretta: B

`<tr>` significa table row, cioè riga della tabella.

## 10. Risposta corretta: A

`<td>` rappresenta una cella dati.

## 11. Risposta corretta: A

`<th>` rappresenta una cella di intestazione.

## 12. Risposta corretta: B

`colspan` unisce più colonne.

## 13. Risposta corretta: A

`rowspan` unisce più righe.

## 14. Risposta corretta: C

`*` è il selettore universale.

## 15. Risposta corretta: B

`.box` seleziona tutti gli elementi con classe `box`.

## 16. Risposta corretta: B

`#header` seleziona l'elemento con id `header`.

## 17. Risposta corretta: B

`padding` crea spazio interno.

## 18. Risposta corretta: A

`margin` crea spazio esterno.

## 19. Risposta corretta: A

Il box model si può leggere come contenuto, padding, bordo, margine.

## 20. Risposta corretta: A

`border` crea un bordo attorno a un elemento.

## 21. Risposta corretta: B

`float:left` affianca/sposta un elemento verso sinistra.

## 22. Risposta corretta: B

`clear:both` interrompe il flusso degli elementi flottanti.

## 23. Risposta corretta: A

`table a` seleziona solo i link dentro una tabella.

## 24. Risposta corretta: A

Lo scope indica il contesto in cui una regola CSS viene applicata.

## 25. Risposta corretta: A

`div` è un contenitore generico.

## 26. Risposta corretta: B

`form` raggruppa campi e controlli per l'invio dati.

## 27. Risposta corretta: B

`for` collega una label al campo con lo stesso `id`.

## 28. Risposta corretta: C

`name` identifica il dato inviato al backend.

## 29. Risposta corretta: A

`id` serve al browser/CSS/JS, `name` serve all'invio del dato.

## 30. Risposta corretta: B

Radio button con lo stesso `name` fanno parte dello stesso gruppo e permettono una sola scelta.

## 31. Risposta corretta: A

La checkbox è adatta per conferme sì/no.

## 32. Risposta corretta: B

`textarea` è adatta a testo più lungo.

## 33. Risposta corretta: A

`select` permette di scegliere un valore da una lista.

## 34. Risposta corretta: A

`required` rende obbligatoria la compilazione del campo prima dell'invio.

## 35. Risposta corretta: B

`reset` cancella o ripristina i valori della form.

## 36. Risposta corretta: A

`submit` invia la form.

## 37. Risposta corretta: B

Una form HTML da sola non salva dati: serve un backend o una destinazione di invio.

## 38. Risposta corretta: A

Gli spazi visuali dovrebbero essere gestiti dal CSS, non da tanti `<br>`.

## 39. Risposta corretta: B

Prima di Flexbox/Grid ha senso capire le basi del layout.

## 40. Risposta corretta: A

HTML descrive la struttura, CSS descrive la presentazione.
