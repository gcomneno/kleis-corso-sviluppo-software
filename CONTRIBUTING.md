# Contributing

Grazie per voler contribuire al progetto 🙌

## 🎯 Obiettivo
Mantenere il repository semplice, leggibile e utile per studenti.

## 📌 Linee guida

- Una esercitazione = un progetto separato
- Nomi chiari e descrittivi
- Codice semplice e leggibile (livello didattico)
- Evitare over-engineering

## 🔧 Workflow

1. Fork del repository
2. Crea un branch:
   git checkout -b feature/nome-feature

3. Fai le modifiche
4. Commit:
   git commit -m "Descrizione chiara della modifica"

5. Push:
   git push origin feature/nome-feature

6. Apri una Pull Request

## 💬 Note

- Spiegare sempre *perché* si fa una modifica
- Il codice deve essere comprensibile anche a principianti
