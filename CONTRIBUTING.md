# Contributing

Grazie per voler contribuire al progetto.

Questo repository nasce come laboratorio condiviso del corso: appunti, esercizi, correzioni, esperimenti e Lesson Learned possono aiutare tutti.

L'idea è semplice:

> se hai capito qualcosa, puoi aiutare qualcun altro a capirla più velocemente.

---

## Cosa puoi contribuire

Puoi proporre:

- appunti presi durante la lezione
- correzioni di errori o refusi
- esempi più semplici
- soluzioni alternative agli esercizi
- spiegazioni passo-passo
- nuove Lesson Learned
- link utili alla documentazione ufficiale
- domande frequenti con risposta
- miglioramenti al README

Non serve scrivere codice perfetto.

Serve scrivere qualcosa di utile, chiaro e comprensibile.

---

## Regole semplici

- Una esercitazione = una cartella chiara
- Nomi dei file descrittivi
- Codice leggibile prima di codice furbo
- Spiegare sempre perché si propone una modifica
- Evitare over-engineering
- Mantenere il livello adatto al corso
- Non cancellare materiale altrui senza motivo

---

## Come contribuire da GitHub, senza terminale

Il modo più semplice è usare direttamente il sito GitHub:

1. Apri il repository su GitHub
2. Entra nel file che vuoi modificare
3. Clicca sull'icona della matita
4. Fai la tua modifica
5. Scrivi un messaggio breve che spiega cosa hai cambiato
6. Proponi la modifica con una Pull Request

Esempio di messaggio:

    docs: aggiungi appunti su Bootstrap

oppure:

    fix: correggi spiegazione sul box model

---

## Come contribuire da terminale

Per chi vuole usare Git:

1. Crea un branch

    git checkout -b docs/miei-appunti-bootstrap

2. Fai le modifiche

3. Controlla lo stato

    git status

4. Aggiungi i file

    git add nome-file.md

5. Crea il commit

    git commit -m "docs: aggiungi appunti su Bootstrap"

6. Pubblica il branch

    git push origin docs/miei-appunti-bootstrap

7. Apri una Pull Request su GitHub

---

## Idee di contributo facili

Se non sai da dove iniziare, puoi fare una di queste cose:

- aggiungere una spiegazione più semplice a una Lesson Learned
- creare un esempio minimo di codice
- aggiungere una domanda frequente
- sistemare titoli e formattazione Markdown
- collegare un esercizio al README
- proporre un confronto tra CSS puro e Bootstrap

---

## Stile consigliato

Scrivi come se stessi aiutando un compagno che ha perso la lezione.

Meglio una spiegazione semplice e utile che una spiegazione elegante ma incomprensibile.

---

## Nota finale

Questo repository non è una gara.

È una piccola officina condivisa: ognuno può aggiungere un bullone, stringere una vite o lasciare un appunto che domani farà risparmiare tempo a qualcun altro.
